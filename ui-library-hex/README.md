# ProofGraph UI Library

Token-driven, skin-swappable React primitives for ProofGraph. Run `npm run dev` to open the playground. Run `npm run typecheck`, `npm run lint`, `npm test`, and `npm run build` before release.

Every styled element follows the two-file pattern: structure and accessibility in `element.tsx`, class strings in `element.recipe.ts`. Elements consume semantic and component tokens, never primitive tokens.
